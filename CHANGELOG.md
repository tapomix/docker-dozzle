# Changelog

All notable changes to this project will be documented in this file.

---

## [0.1.0] - 2026-01-21

### Added

- Docker Compose configuration for Dozzle with Traefik integration
- Socket proxy support for secure Docker API access
- Multi-host configuration via `DOZZLE_REMOTE_HOST`
- Optional authentication with simple auth provider
- Security hardening (read-only filesystem, dropped capabilities, resource limits)
- Documentation with socket proxy permissions and authentication setup
